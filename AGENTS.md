## What this repo is

`base-template` is a minimal skeleton used as the starting point for new
`theholocron` repositories that do not ship code (no `package.json`). It
provides the standard `.github/` workflow set, repo configuration, and
`holocron.config.json` placeholders that every repo needs.

When creating a new repo from this template, replace every `<placeholder>`
in `holocron.config.json` and update this file with repo-specific guidance.
